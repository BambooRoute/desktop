# 架构边界

## 已选方向与当前状态

采用官方 DeepSeek Harness 的 Electron 桌面壳、本地 Host 和插件体系。当前尚未导入这些组件，也未验证 Bamboo 接入。

| 层级 | 职责 | 不承担的职责 |
| --- | --- | --- |
| 桌面 UI | 账户入口、会话、模型选择、工作区、任务状态和消费展示 | 保存长期凭据、裁定账户权限、计算最终账单 |
| 桌面主进程与凭据适配 | 系统集成、设备授权回调、凭据存取、Host 生命周期 | 保存上游厂商密钥、执行服务端管理操作 |
| 本地 Host 与 Agent | 会话编排、工具调用、工作区访问、模型请求、任务恢复 | 复制云端钱包或私自增加账户额度 |
| BambooRoute 后端 | 账户、设备授权扩展、模型目录、网关、定价、余额及结算 | 默认接收整个本地工作区 |
| 模型供应商 | 执行经网关转发的模型调用 | 接收 Bamboo 账户密码或设备刷新凭据 |

UI 经受控接口操作本地 Host；Host 经 BambooRoute 模型网关调用模型。账户、支付和设备管理由 BambooRoute 后端提供相应接口。

## 现有后端契约

2026-11-10 查看了现有后端工作区的 [API 文档](https://github.com/ly95/BambooRoute/blob/main/docs/API.md)及相关实现。远端内容可能落后于本地未提交修改；具体接入时重新核对双方的已锁定提交。

- 网站与账户接口使用 `https://bambooroute.com`。
- 模型调用基址为 `https://api.bambooroute.com/v1`，Gemini 原生接口使用 `/v1beta`。
- 浏览器 `/api` 接口使用会话 Cookie，变更请求需要 CSRF 校验。
- 模型接口接受 Bamboo 平台凭据；不同协议的鉴权头按现有契约处理。
- 模型能力与协议分别声明，不保证任意协议之间自动转换。
- 金额和价格使用服务端十进制字符串及明确单位，展示不得用浮点重算替代结算结果。

以上不表示现有网站会话已能直接用于原生桌面授权。不要把浏览器 Cookie 复制进模型配置或工作区。

## 计划中的桌面授权

桌面应用通过系统浏览器打开 Bamboo 授权流程，完成后安全返回应用。计划采用适用于原生客户端的授权码与 PKCE 机制，服务端签发可按设备撤销的凭据。

该流程需要后端新增对应能力。设备接口、回调地址、令牌格式、有效期、刷新轮换、撤销方式和客户端标识均尚未定稿，当前不预留虚假的已实现 API 路由。

长期凭据交由操作系统凭据存储管理；渲染 UI、项目文件、日志、命令行参数和模型上下文不得获得长期凭据。模型调用所需授权由受控的凭据适配层提供，不能默认将刷新凭据直接作为 API Key 使用。

实现时验证登录取消、重复回调、授权过期、刷新失败、退出、设备撤销和账户切换。浏览器登录、支付返回和设备回调分别校验，不以页面跳转作为成功依据。

## 模型与计费

优先通过上游模型适配插件连接 Bamboo 网关，由服务端提供模型标识及能力。`llm-pi-ai` 的兼容网关能力是候选接入点，需要在锁定版本下验证。

每个拟发布模型至少覆盖流式输出、工具调用及工具结果回传、取消、上下文恢复和错误映射。图片、推理字段及其他能力分别验证，不从文本请求成功推断可用。

标题生成、压缩、子任务等辅助调用也必须经过 Bamboo 网关，纳入同一账户的消费和记录。不能只替换主会话请求地址而遗漏辅助模型调用。

服务端负责余额检查、预留、结算和最终价格。客户端记录请求关联信息，用于任务聚合与对账。网络断开或取消不代表零消费；结果不明时先查询记录，再决定是否重试。

## 本地执行与数据

- 工作区访问和命令执行遵守用户授权范围；保留上游权限机制并验证定制未绕过它。
- 修改文件前后的差异、工具状态和恢复能力按真实实现展示。
- 回环 Host 需要认证、请求来源约束和进程生命周期管理，不复用固定公开凭据。
- 会话与文件缓存按账户隔离；退出、切换、卸载及重新登录的数据行为在实现前明确。
- 项目内容和工具输出不能自行授权额外目录、命令或凭据访问。
- 按任务需要传输模型上下文，避免默认扫描并上传整个工作区。
- 遥测、崩溃报告和诊断上传的数据范围、开关及接收方需要明确，不能直接继承上游生产收集地址。

## 发行隔离

Bamboo 使用独立的应用 ID、URL 协议、数据目录、系统凭据命名空间、更新服务和签名配置。不要覆盖官方 DeepSeek Harness 的安装、登录状态或自动更新配置。

运行时与所需工具应随安装包提供或有明确的产品内准备流程。具体依赖、包管理器和版本以最终接入的上游锁文件为准，当前不编造版本约束。
